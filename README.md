# HungryCoach — тестовое задание

Прототип tower defense с симуляцией на основе дискретных тиков. Снаряды выпускаются пушками, проходят через здания-усилители и поражают мишени.

## Механики

- **Пушка (Gun)** — стреляет снарядами. Поддерживает два режима: ручной (по кнопке) и авто (по кулдауну)
- **Усилитель урона (Damage Boost)** — умножает урон снаряда при прохождении через здание
- **Усилитель пробития (Pierce Boost)** — увеличивает количество целей, которые снаряд может поразить
- **Копирование (Copy)** — создаёт копию снаряда с уменьшенным уроном в начале лейна

Здания размещаются drag'n'drop из панели внизу экрана в слоты на лейне. Перетащить здание за пределы слота — удалить его.
Можно переключать режим стрельбы - в **MANUAL** режиме пушки стреляют по кнопке, в **AUTO** - по кулдауну.
Есть контрол управления скоростью симуляции. 0 - пауза, ничего не двигается, 10 - x10 от обычной скорости.

## Настройка геймплея

Все параметры геймплея хранятся в одном ScriptableObject:

```
Assets/_Project/ScriptableObjects/GameplayConfig.asset
```

### Lanes

Количество лейнов определяется размером списка **Lanes**. Каждый элемент списка — отдельный лейн со своими настройками:

| Параметр | Описание |
|---|---|
| `Build Slot Count` | Количество слотов под здания |
| `Target Health Values` | Список HP мишеней на этом лейне |

### Настройка зданий

Каждое здание конфигурируется отедльным ScriptableObject:

```
Assets/_Project/ScriptableObjects/Buildings/
```

#### Gun
| Параметр | Описание |
|---|---|
| `Projectile Damage` | Базовый урон снаряда |
| `Projectile Speed` | Скорость снаряда |
| `Projectile Hits` | Количество целей, которые может поразить снаряд |
| `Fire Interval` | Интервал между выстрелами в режиме Auto |
| `Initial Cooldown` | Начальный кулдаун при старте или смене режима |
| `Spawn Offset X` | Смещение точки спавна снаряда относительно здания |

#### Damage Boost
| Параметр | Описание |
|---|---|
| `Damage Multiplier` | Множитель урона снаряда |

#### Pierce Boost
| Параметр | Описание |
|---|---|
| `Hits Bonus` | Добавляет Pierce + N снаряду |

#### Copy
| Параметр | Описание |
|---|---|
| `Copy Damage Fraction` | Доля урона оригинала у копии (0.5 = 50%) |

### Layout

| Параметр | Описание |
|---|---|
| `Lane Base Y` | Y-позиция первого лейна |
| `Lane Spacing` | Расстояние между лейнами по вертикали |
| `Lane Start X` | X-позиция начала лейна |
| `Lane Length` | Длина лейна (чтобы снаряды не улетали в бесконечность) |
| `Build Slot Spacing` | Расстояние между слотами под здания |
| `Building Slots Offset X` | Смещение первого слота от начала лейна |
| `First Target Offset From Building` | Расстояние от последнего слота до первой мишени |
| `Targets Spacing` | Расстояние между мишенями |
| `Target Offset X` | Смещение точки попадания относительно центра мишени |
